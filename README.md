# TriCube Companion

An elegant, mobile-first companion app for the **TriCube Tales** roleplaying game system. Designed for travel and accessibility, this Progressive Web App (PWA) replaces dice, character sheets, and oracle tables with a single, streamlined interface.

## Play Now
**[Launch App](https://netanel-m.github.io/TriCube-Tales-Companion-App/)**

## Features
- **All-in-One Interface**: Track stats, roll dice, and generate story ideas instantly.
- **Genre Support**: Built-in archetypes, perks, and quirks for multiple settings.
- **Smart Dice Roller**: Automatically calculates success and adjusts Karma based on game rules.
- **Oracle Generator**: Spark ideas with a genre-agnostic oracle for GM-less or solo play.
- **Offline Capable**: Installable as a native-feeling app on iOS and Android.

## Getting Started

### Installation
This is a Progressive Web App (PWA). You can run it directly in your browser or install it for a full-screen experience:
1.  **Visit the URL**: Go to the link above on your mobile device.
2.  **Add to Home Screen**:
    *   **iOS (Safari)**: Tap "Share" → "Add to Home Screen".
    *   **Android (Chrome)**: Tap "Menu" (three dots) → "Install App" or "Add to Home Screen".
    *   *Note: On some devices, you may need to interact with the page for ~30 seconds before the install prompt appears.*

### How to Play

#### 1. Character Creation
*   Ensure all players select the same **Genre** to share the setting's tone.
*   Select an **Archetype** (composed of a Trait and Concept).
*   Choose one **Perk** (special ability) and one **Quirk** (flaw).
*   Enter your **Name** to begin.

#### 2. Gameplay
*   **Challenges**: The GM sets a difficulty (Standard is Target Number 5).
*   **Rolling**:
    *   Select if your **Trait** (3 dice) or **Concept** (2 dice) applies to the action.
    *   Toggle a **Perk** to lower the difficulty (costs 1 Karma).
    *   Toggle a **Quirk** to increase difficulty (gains 1 Karma on failure, 1 Resolve on success).
*   **Resolution**: The app automatically tracks successes and resource usage. If you fail and suffer consequences, use the "Accept Failure" button to reduce Resolve.

#### 3. Session End & Leveling Up
*   Click **End Session** to wrap up the adventure.
*   The GM will guide you through the level-up process:
    *   **Odd Levels**: Choose a new Perk or Quirk.
    *   **Even Levels**: Increase maximum Karma or Resolve.
