# TriCube Tales Companion App
I made this Progressive WebApp to allow mw to play TriCube Tales when traveling without dice, paper. I wanted an easy way to track characters, do rolls and generate simple ideas with oracles all from one page.

Play [here](https://netanel-m.github.io/TriCube-Tales-Companion-App/)
